# Medusa v2 Backend

## Setup
1. `npm install`
2. Ensure Postgres is running.
3. `npm run dev`
4. `npm run seed`

## Environment Variables
- `DATABASE_URL`: Postgres connection string.
- `MEDUSA_PUBLISHABLE_KEY`: Generated by seed, copy to storefront.
- `COOKIE_SECRET`: Dev secret.

## Dev Checks
- Admin: http://localhost:9000/app
- Health: `./scripts/health.sh`
